# Inteligência Artificial Aplicada à Pesquisa Científica

Este repositório contém meu progresso, scripts e projetos desenvolvidos durante o curso de extensão focado na aplicação prática de programação e Inteligência Artificial (Deep Learning) para pesquisa científica. 

O objetivo principal é o processamento e a análise de dados e imagens reais, construindo uma base sólida desde os conceitos iniciais de Python até a implementação de modelos de aprendizagem profunda. O curso foca estritamente em classificação e segmentação clássica em pesquisa (não abordando IA generativa ou LLMs).

## 📚 Estrutura do Curso e Progresso

Abaixo está o cronograma de módulos do curso, acompanhado do meu status atual de acompanhamento:

* **Módulo 1:** Fundamentos de Python para Ciência de Dados *(Concluído)*
* **Módulo 2:** Introdução à Aprendizagem de Máquina *(Concluído)*
* **Módulo 3:** Fundamentos de Classificação com Aprendizagem Profunda / Fundamentos de Segmentação com Aprendizagem Profunda *(Em andamento)*
* **Módulo 4:** Desenvolvimento de Miniprojetos com Modelos de Classificação e Segmentação *(Em breve)*

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Machine Learning / Deep Learning:** PyTorch
* **Manipulação de Dados:** Pandas, tensores Pytorch
* **Ambiente:** Google Colab

## 📂 Organização do Repositório

* `/modulo_2_python/`: Exercícios de nivelamento em Python para análise de dados.
* `/modulo_3_machine_learning/`: Códigos e implementações de introdução aos modelos de aprendizagem de máquina.
* `/modulo_4_deep_learning/`: Construção e avaliação de redes neurais (MLP, etc.) para classificação e segmentação.
* *(Em breve)* `/modulo_5_projeto_final/`: Miniprojeto aplicado.
