# Dados do laboratório LIPAI

Alguns notebooks precisam de dados para serem executados e estes dados estão disponíveis neste repositório.

Os arquivos na pasta `/respostas` contêm os dados de saída dos notebooks, que foram gerados depois de executar os notebooks com os dados de entrada originais. Estes arquivos são fornecidos como prova de que foi feito o exercício e dispõem de uma referência para comparação com os resultados obtidos ao executar os notebooks com os dados de entrada originais.
